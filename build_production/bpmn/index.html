Saccharine BPMN
Automate workflows visually.

A process orchestrator for Laravel that turns flowcharts into durable background queue jobs.

Get Started →
Live Sandbox ↗

1. Draw the Process

Use a visual, drag-and-drop web canvas to map out a business process. Connect tasks, set routing rules, and define the finish line.

2. The Engine Takes Over

The software reads your drawing like a set of instructions. It silently moves behind the scenes, following the exact paths and logic you designed.

3. Work Gets Done

It reacts to events, halts for human approvals, and runs system tasks, automating operational overhead.

Built on proven foundations

saccharine/bpmn unites industry-standard tools into a cohesive, native Laravel package.

bpmn-js (Camunda)

Powers the embeddable visual SVG modeler, custom palettes, and live execution telemetry tracking.

Camunda / bpmn.io
durable-workflow

Deterministic coroutines, database snapshots, and inbox signals for human-in-the-loop tasks.

durable-workflow.com
Symfony Expression

Evaluates Exclusive Gateway routing rules safely against payload state without PHP eval().

symfony.com
Native Laravel

Runs entirely on your existing queues (Redis/SQS/DB) and standard Eloquent relational migrations.

laravel.com
