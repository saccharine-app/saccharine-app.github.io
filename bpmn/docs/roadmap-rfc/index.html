Roadmap & Request for Comments (RFC)

saccharine/bpmn is currently in active development under v0.5.0-alpha. We are gathering real-world architectural feedback, testing engine assumptions across enterprise use cases, and inviting contributions from the Laravel community.

Current Status: What Works Today

The core execution loop and relational compilation layers are stable and tested under PHP 8.3/8.4 and Laravel 12/13 via Pest:

  • Strict XPath XML Parsing: Validates and converts BPMN 2.0 XML into relational graph tables (workflow_definitions, versions, nodes, edges).
  • Durable Coroutine Execution: Deterministic replay safety and database state snapshots powered by durable-workflow.
  • Service Task Delegation: Asynchronous delegation to registered activity classes with automatic payload mutation merging.
  • User Task Hibernation: Suspends processes cleanly without blocking queue workers; wakes when inbox signals are dispatched.
  • Exclusive Gateways (XOR): Safe expression evaluation via Symfony ExpressionLanguage without raw PHP eval().
  • Parallel Gateways (AND): Spawns concurrent branch coroutines and resolves synchronization join barriers via yield all().
  • Sub-Processes & Call Activities: Scoped execution of modular sub-graphs with parent_element_id isolation.
  • Visual Modeler: Embedded bpmn-js canvas driven by an engine capability registry with filter middleware for the palette, context pad, and replace menu, along with Camunda element template support.
  • Live Token Cockpit: Interactive SVG telemetry overlay with real-time status polling.
  • Filament Integration: Standalone Blade dashboard plus optional php artisan bpmn:filament stub scaffolding for embedding BPMN resources into an existing Filament v5 panel.

Known Boundaries & Limitations

As an early alpha, several advanced BPMN 2.0 specifications are not yet supported:

  1. Complex / Inclusive Gateways (OR Splits):
    Only Exclusive Gateways (XOR) and Parallel Gateways (AND) are currently supported. Multi-condition inclusive path evaluation (OR) is under active research.
  2. Intermediate In-Flight Catch Events:
    Message and signal start events are supported, but intermediate in-flight message catch events are currently routed through User Task signals rather than dedicated event nodes.
  3. In-Flight Schema Migration:
    When a new version of a workflow diagram is published, active running instances remain pinned to the specific version (workflow_version_id) they began on. Dynamic token migration across schema versions is not yet implemented.
  4. Compensation & Transaction Boundaries:
    Automated business rollbacks (Saga compensation events) must currently be handled manually within activity classes rather than declared via visual BPMN compensation boundaries.

Upcoming Milestones: The Path to Beta & v1.0

Milestone 1: Timer Intermediate Events & Durations

  • Add support for standalone Timer Catch Events and Boundary Interrupting Timers.
  • Enable ISO 8601 duration syntax (e.g., P1D, PT2H) using the engine's awaitWithTimeout() coroutine helper to trigger automated fallback paths if tasks stall.

Milestone 2: Declarative Data Input/Output Mapping

  • Add declarative input/output data transformers directly to the visual canvas properties panel.
  • Allow developers to scope and reshape $userData keys entering and exiting a Service Task without writing custom data-mapping boilerplate in PHP.

Milestone 3: Dynamic Simulation & Token Replay

  • Introduce an interactive "dry run" simulator in the visual modeler.
  • Allow developers to test gateway conditions and inspect hypothetical execution paths in the browser using mock JSON payloads before deploying workflows.

How to Contribute & Join the RFC

We welcome RFC discussion, bug reports, and pull requests.

Areas Where We Need Feedback

  • Gateway Evaluation Ergonomics: Does Symfony ExpressionLanguage meet your routing criteria, or do you require custom business rule engine bindings?
  • Edge-Case Exception Handling: How do your queue workers prefer to handle third-party API downtimes—infinite queue retries or visual error boundary branches?
  • Filament Experience: How can the workflow cockpit and token inspector better serve daily operational triage?
