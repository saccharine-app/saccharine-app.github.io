Quickstart Guide

Get up and running with saccharine/bpmn in under five minutes. This guide covers package installation, running migrations, and triggering the pre-packaged demo workflow.

Requirements

  • PHP:8.4
  • Laravel Framework:13.0
  • Database: MySQL 8+, MariaDB 10.3+, PostgreSQL 13+, or SQLite 3.35+
  • Queue Driver: Redis, Database, or SQS (Sync queues can be used for local testing, but persistent background workers are recommended for durable workflows)

1. Installation

Install the package into your Laravel application via Composer:

composer require saccharine/bpmn

Run the interactive package installer command:

php artisan bpmn:install

This automated command handles initial setup:

  1. Publishes the configuration file to config/saccharine-bpmn.php.
  2. Publishes migration files for workflow blueprints, runtime tokens, and history ledgers.
  3. Runs the migrations to establish database tables.
  4. Publishes pre-compiled assets for the embedded bpmn-js visual canvas and live cockpit.

2. Seed the Demo Workflow

The package includes an end-to-end order processing scenario with Exclusive Gateways, User Task approval pauses, and automated notification activities: 

php artisan db:seed --class='Saccharine\Bpmn\Database\Seeders\BpmnDemoSeeder'
php artisan bpmn:publish-filament-stubs

The demo configures:

  • An Order Processing BPMN 2.0 XML graph compiled into relational definition tables.
  • A sample domain activity class: App\Workflows\Activities\SendNotificationActivity.
  • Pre-mapped test payloads with sample order values and customer contact data.

3. Running the Engine

Open two separate terminal windows in your project directory:

Terminal A: Start Queue Workers

Start your standard Laravel queue worker to process workflow steps:

php artisan queue:work

Terminal B: Dispatch a Workflow Instance

Trigger the demo process using the test CLI command:

# Triggers an order requiring human approval (total >= 1000)
php artisan bpmn:test-order --amount=1500 --name="Demo Customer" --email="demo@example.com"

Your terminal will output the execution lifecycle:

[BPMN:ENGINE] [#1] (Start_OrderPlaced) Process started from node [Start_OrderPlaced].
[BPMN:GATEWAY] [#1] (Gateway_VIP) Evaluated conditions. Routing token -> [Task_ManualReview].
[BPMN:HIBERNATE] [#1] (Task_ManualReview) User Task [Manager Review] reached. Workflow hibernating in database awaiting signal.

4. Inspecting the Visual Cockpit

Navigate to the standalone workflow instances dashboard in your browser:

http://your-app.test/bpmn/workflows/instances
Note: The default web prefix is `bpmn/workflows`. You can configure this in `config/saccharine-bpmn.php` under `prefix.web`. If you have Filament v5 installed, the package auto-detects the panel and mounts under /admin/bpmn/instances instead.

From the dashboard:

  1. For the running instance of Demo: Order Processing click Live Cockpit.
    • Completed nodes are styled in solid slate blue.
    • The waiting User Task node pulses in vivid green.
  2. Click the pulsing node to open the approval modal, then select Submit & Resume.
  3. Watch your queue worker wake the coroutine, advance the token past the join, trigger SendNotificationActivity, and complete the process at the End Event.

Artisan Scaffolding Helpers

Generate workflow components directly from the CLI:

# Create a new custom Service Task Activity
php artisan bpmn:make-activity ProcessPaymentActivity

# Create a Message/Event Trigger listener
php artisan bpmn:make-trigger OrderPaidTrigger

# Create a Camunda-compatible Element Template JSON definition
php artisan bpmn:make-template payment-service
